    同步到仓库

    这个网站是纯静态的，没有服务器帮忙写文件，所以「写进仓库」这一步要借 GitHub 的一条 issue 当传话筒。 跳过去是正常的，三步做完大概一分钟自动生效。

    1. ① 打开 GitHub 提交页 点下面的按钮，新标签里会有一条已经填好内容的 issue，标题叫 Excluded Papers。
    2. ② 点绿色的「Create」 在页面右下角（手机上在最底部），正文一个字都不用改，直接创建。
    3. ③ 回来点「我已提交」 机器人会把这几篇写进永久排除清单，以后每周筛选都不再收。

    嫌麻烦？配一次令牌，以后真的点一下就同步

    去 GitHub 令牌页 新建 fine-grained token：Repository access 选 Only select repositories → 本仓库； Permissions 里只把 Issues 改成 Read and write，其余全部留 No access。 生成后粘到下面，只存在你自己这台电脑的浏览器里，不会上传到任何地方。
